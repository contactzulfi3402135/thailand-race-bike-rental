# APEX9 Motorsport — Thailand Race Bike Rentals & Track Days

Turnkey multilingual motorsport web application built with React 19, TypeScript, Tailwind CSS v4, and Framer Motion.

## Features
- **Full-Screen 60fps Track & Cockpit POV Video Hero** (`public/videos/`)
- **Hybrid Conversion Layout**: Full one-page experience + dedicated per-bike configurator pages (`#/bike/:slug`)
- **Trilingual Support**: Native English (`EN`), Thai (`ไทย`), and Simplified Chinese (`中文`) + live `USD` / `THB` / `CNY` currency switching
- **Booking & Messaging Engine**: Dynamic package calculator wired to WhatsApp, Facebook Messenger, LINE, WeChat, and direct enquiry intake
- **Owner Self-Service CMS (`/#cms`)**: Visual editor to update bike rates, copy in all 3 languages, custom video URLs, and contact channels

## Deployment (Vercel)
1. Push repository to GitHub via GitHub Desktop.
2. Import repository in Vercel (auto-detected as **Vite**).
3. Click **Deploy** — zero environment variables required.
